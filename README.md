## 🔧 Troubleshooting Common Issues

### Problem: The app won't start.
- Make sure you downloaded the correct file for Windows.
- Try right-clicking the downloaded file and selecting "Run as administrator."
- Check if your antivirus is blocking it - if so, allow linksift through.

### Problem: Downloads are slow.
- Close other programs that use the internet (streaming, gaming, etc.).
- Try a lower quality setting, which results in smaller files.
- Pause and resume the download if the app allows it.

### Problem: I can't find my downloaded files.
- By default, linksift saves to a folder called "linksift" in your Documents or Downloads folder.
- You can change the save location in the app's settings (look for a gear icon).

### Problem: The website I want isn't supported.
- Check if linksift gives an error like "This URL is not supported." If so, that site may be difficult to download from. 
- Try searching online for alternative sites that host the same content.
